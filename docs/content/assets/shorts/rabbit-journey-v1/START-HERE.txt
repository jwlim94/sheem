SHEEM — RABBIT JOURNEY SHORT
23 seconds / 1080 × 1920 / 30 fps / English narration

가장 쉬운 CapCut 편집 방법
1. 새 프로젝트에 rabbit-journey-23s-clean.mp4 하나를 넣는다.
   이미지 크롭, 약한 확대, 컷 순서는 이미 적용되어 있다.
2. edit/voiceover-en.txt를 읽어 직접 녹음한다.
   편안한 대화 톤으로, 각 문장의 시작을 timeline.csv 시간에 맞춘다.
   문장이 빠듯하면 해당 컷을 조금 늘린다. 23초를 억지로 맞출 필요는 없다.
3. edit/captions-en.srt를 자막으로 가져온다. 실제 녹음에 맞춰 타이밍을 조정한다.
4. 자막은 흰색 굵은 산세리프, 얇은 어두운 테두리, 최대 두 줄.
   1080×1920 기준 글자 약 48px, 화면 아래에서 350~420px 위에 배치한다.
   얼굴/가방을 가리지 않는지 실제 화면에서 확인한다.
5. 마지막 19~23초에 작은 'sheem.' 텍스트를 위쪽에 넣는다.
   다른 장식, 스티커, 전환 효과는 넣지 않는다. 기본 하드컷을 유지한다.
6. 1080×1920, 30fps로 내보낸다.

다시 편집하려면
clips/01~07을 파일 번호 순으로 가져오면 같은 23초가 된다.
전체 가편집과 개별 클립을 동시에 타임라인에 넣지는 않는다.
images/에는 사용한 원본 PNG 4장이 있다.
edit/timeline.csv에는 초별 화면, 영어 녹음 문장, 선택형 제목이 있다.
제목은 전부 넣지 말고, 필요하면 첫 컷의 'From image to 3D'만 사용한다.

소리
제공한 MP4는 모두 무음이다. 녹음, 음악, 현장 소리는 포함되어 있지 않다.
이번 편은 내레이션만으로 완성한다. 가짜 키보드/제작 소리는 추가하지 않는다.
