# Male character candidates — 2026-10-10

User direction: a college-age male wearing a backpack, walking to BYU and briefly experiencing campus life. Use Sheem's warm, quiet palette. This is asset research, not a final character selection or a deployed scene. The eventual story excludes Fitzza and includes a BYU master's chapter focused on Security and Business; education dates remain unconfirmed.

## Downloaded animation reference

`human-male-animation-reference.glb`: Quaternius Superhero Male base with Universal Animation Libraries 1 and 2 combined by NafisRayan. This is an adult muscular base, **not an approved college-boy appearance**. Use it to evaluate the humanoid skeleton and authored motions before choosing final proportions/clothing. Backpack, student clothing, expressive face animation, and walking quality have not been validated.

- Original creator: https://quaternius.com/packs/universalbasecharacters.html
- Download mirror: https://github.com/NafisRayan/Animate-Rigged-Humanoid-No-Blender/blob/main/test/human_male.glb
- Mirror documentation: https://github.com/NafisRayan/Animate-Rigged-Humanoid-No-Blender
- Original asset/animation license: CC0, license files retained as LICENSE-1/2/3.txt. No repository code was executed or incorporated.
- Binary structure validated: 35,190,592 bytes, one skin, three meshes, 86 animation entries. Contains Walk_Loop, Walk_Carry_Loop, Idle_Loop, Sitting_Enter, Sitting_Idle_Loop, Sitting_Exit. Duplicate A_TPose clip names should be resolved before production use.
- `inspection.json`: complete animation inventory and SHA-256. These are file-level checks, not visual animation acceptance.
- Kept outside `public/` to avoid shipping the 35 MB research asset. Extract only chosen model/animations and optimize after approval of visual direction.
